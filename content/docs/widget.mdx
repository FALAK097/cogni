title: Widget configuration
description: Configure the visitor-facing widget, launcher, welcome content, and suggested questions.
---

Widget settings control the visitor-facing chat experience. Configure them from **Agent → Deploy**, then publish to make changes live.

## Appearance and launcher

Use the customization controls to set the widget appearance, launcher treatment, colors, corner radius, and screen position. Preview the result at desktop and mobile widths before publishing.

Keep launcher text short enough to fit narrow screens, and maintain visible contrast between text, controls, and their backgrounds.

## Conversation content

Configure the welcome message, preview message, visitor input placeholder, and suggested questions. Suggestions should represent useful starting tasks that the indexed knowledge can answer.

The agent name, brochure button label, privacy-policy URL, and lead-capture behavior come from **Agent → Build**.

## Preview and publication

The preview reflects the current draft. The embedded website widget reflects the latest successful publication. This separation lets owners validate visual and behavioral changes without changing the live experience.

After publishing, verify the widget on an authorized production hostname. Continue with [Widget installation](/docs/widget-installation) for the loader, domain matching, and CSP.
