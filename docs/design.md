# Cogni Design System v1.0

> Brand guidelines for Cogni - AI Omnichannel Customer Support Platform

---

# Brand Philosophy

Cogni should feel:

- Intelligent
- Enterprise-grade
- Fast
- Minimal
- Premium
- Trustworthy
- Calm
- Modern

Not playful.
Not overly animated.
Not futuristic with glowing neon.
Not overly colorful.

Think:

- Stripe
- Linear
- Vercel
- Notion
- Intercom

# Design Principles

Whitespace is a feature.

Remove unnecessary decorations.

Keep interfaces calm.

Every element should have a purpose.

Prefer clarity over creativity.

Never sacrifice usability for aesthetics.

Consistency beats uniqueness.

Users should understand the interface instantly.

---

# Things to Avoid

❌ Gradients

❌ Neon colors

❌ Glassmorphism

❌ Heavy shadows

❌ Excessive animations

❌ Floating random shapes

❌ Rounded 40px buttons

❌ Huge icons

❌ Tiny click targets

❌ Different button styles on same page

❌ Random font sizes

❌ Multiple accent colors

❌ More than one primary CTA per section

❌ Inconsistent spacing

❌ Inconsistent border radius

---

# AI Prompt Rules

When generating UI:

- Follow this design system exactly.
- Use Geist typography.
- Use only the defined color palette.
- No gradients.
- No unnecessary animations.
- No glow effects.
- No glassmorphism.
- No skeuomorphism.
- Use subtle hover states only.
- Keep layouts spacious with generous whitespace.
- Maintain consistent spacing using the 4px grid.
- Use rounded corners according to the design system.
- Design should feel premium, enterprise, and modern.
- Prioritize accessibility, readability, and responsiveness.
- Every component should look consistent across the product.
