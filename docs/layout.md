# Cogni Layout System v1.0

> Page layouts, spacing, responsive behavior and composition rules.

---

# Philosophy

Every page should answer these questions in under 3 seconds.

1. Where am I?
2. What can I do here?
3. What is the primary action?
4. What information matters most?

Hierarchy should always be obvious.

# Golden Rules

✓ Keep hierarchy obvious

✓ Keep layouts predictable

✓ Never overload one screen

✓ One primary goal per page

✓ One primary CTA per section

✓ Plenty of whitespace

✓ Mobile-first thinking
