# Cogni Copywriting Guide v1.0

> Writing guidelines for Cogni — AI Omnichannel Customer Support Platform

---

# Brand Voice

Cogni should sound:

- Professional
- Helpful
- Confident
- Intelligent
- Friendly
- Concise
- Human

Never sound robotic.

Never sound overly excited.

Never use unnecessary marketing buzzwords.

Write like a knowledgeable teammate.

---

# Tone

Think:

Stripe

Linear

Notion

Intercom

Vercel

GitHub

Avoid:

Duolingo

Discord

TikTok

---

# Principles

Write clearly.

Keep sentences short.

Prefer clarity over cleverness.

Avoid filler words.

Don't over-explain.

Don't use technical jargon unless the audience expects it.

Always explain errors in plain English.

---

# Capitalization

Use sentence case everywhere.

✓ Create agent

✓ Customer inbox

✓ Billing settings

✗ CREATE AGENT

✗ Customer Inbox

---

# Punctuation

Avoid excessive punctuation.

✓ Agent created successfully.

✗ Agent created successfully!!!

Use periods for descriptions.

Avoid periods on buttons.

---

# Grammar

Use active voice.

✓ Invite your teammate.

✗ Your teammate can be invited.

---

# Numbers

Use numerals.

✓ 5 agents

✓ 12 conversations

Not

five agents

---

# Dates

---

# Destructive Actions

Always be explicit.

Delete workspace

Delete conversation

Disconnect Slack

Remove integration

Never use generic "Delete" if multiple items exist.

# AI Responses

Sound natural.

Be transparent.

Never pretend.

If uncertain

"I'm not sure about that."

"I couldn't find that information."

"I may be mistaken."

Never hallucinate.

# Golden Rule

Every sentence should answer one question.

If a word can be removed without changing the meaning, remove it.

Write for busy professionals, not marketers.
